# Rocket Portfolio

This repository documents my engineering contributions to our high school rocketry project. My work focuses on embedded programming, custom PCB design, flight-control systems, and physics-based simulation.
## Projects
### Divinity - Flight Computer

A custom rocket flight computer featuring sensor integration, quaternion-based orientation estimation, PID thrust vector control (TVC), and recovery-control logic.

The directory includes my firmware, KiCad PCB designs, and technical documentation.
### Genesis - Launch-Pad Controller

An ESP32-based launch-pad controller featuring a wireless web interface, four-servo control, and launch-sequence management.

The directory includes the original firmware and custom PCB design files. Genesis was tested on the physical PCB and used during some of our model-rocket launches.
### Rocket Flight Simulator

A Python-based simulation developed to study rocket flight dynamics and control behavior.

The simulator uses mathematical modeling and numerical integration to investigate rocket motion and experimental flight-control strategies.
## My Contributions

I developed the embedded firmware, designed the electronic circuits and PCBs, and programmed the flight simulation.

The rocket's physical airframe and structure was built by my teammate Isaiah Cardenas. Our project was developed with guidance from our teacher, Mr. Joaquin Llanes, who also mentored me in the mathematical work.
## Project Status

The repository contains completed development work alongside experimental features and designs that are still being refined. Some PCB features are not implemented in the corresponding firmware versions.

An autonomous powered landing remains a future goal rather than a completed result.

Additional technical details, dependencies, and development notes are provided in each project's README.
